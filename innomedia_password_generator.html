InnoMedia Password Generator

Generate the device-specific innomediaadmin service password from the unit's MAC address.

Tested with an InnoMedia MTA8328-1N, hardware A4.1, firmware 1.0.10.3. Other models and firmware versions may use the same algorithm, but have not been verified.

This generates the innomediaadmin password for the serial console, Telnet, and SSH management CLI. It does not work with the web interface login.

What is this?

This utility reproduces the device-specific password used by the hidden innomediaadmin service account on the tested MTA8328-1N.

How this was found

I was given an MTA8328-1N to reuse as a VoIP adapter and initially could not administer it. The normal login problem turned out to be simple: the account is Admin, with a capital A. By then I had already dumped and examined the firmware, which led to the innomediaadmin account and its MAC-based password algorithm.

Compatibility

Verified on the InnoMedia MTA8328-1N, hardware A4.1, firmware 1.0.10.3. Other models and firmware versions may work, but are unverified.

Offline use

This page is self-contained and works offline. The generator makes no network requests after the page is loaded. After you change the MAC address, it is saved only in browser localStorage; the default placeholder is not saved, and cookies are not used. localStorage is not automatically transmitted to the web server. When the page is opened directly with file://, persistence of local storage is browser-dependent. Source, technical details, and the full reverse-engineering story are in the GitHub repository.

Use this only with devices you own or have permission to administer.
